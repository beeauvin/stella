# Reference

This reference describes Stella as it stands today, and it grows as the
language does. Each rule links to the tests that check it, or says it isn't
tested yet.

Here is the smallest Stella program. For now, every program is this one, give
or take [comments](comments.md) and blank lines:

```stella
function main() returns Void {
}
```

- [Source text](source-text.md): what a source file may contain.
- [Functions](functions.md): how a function is written.
- [Types](types.md): the types there are.
- [Comments](comments.md): how a comment is written.
- [Layout](layout.md): the one way code is laid out.
- [Keywords](keywords.md): the keywords so far.
