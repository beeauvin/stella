# Functions

A function is written in this order: the [keyword](keywords.md) `function`, its
name, `()`, the keyword `returns`, a [type](types.md), and then a body in
braces.

```stella
function main() returns Void {
}
```

A function returns a value of exactly one type.

For now:

- The only function is `main`.
- It takes no parameters, so its parentheses are empty.
- It returns `Void`.
- Its body is empty, apart from any [comments](comments.md).
